# Contador de Tecidos

App de celular que conta, pela câmera ao vivo, as cangas **certas** (penduradas no suporte)
e **erradas** (jogadas para a saída). Abra pelo endereço do GitHub Pages deste repositório,
toque em **Ligar câmera** e permita o acesso.

O código-fonte e os testes ficam em `ph771/App-With-CLAUDE` (pasta `app/contador`).
Nada é enviado para a internet: a imagem é analisada no próprio celular.
